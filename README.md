## 🛠️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/GohilVijay07/Data-Structur.git
```

### 2. Open the Project

```bash
cd Data-Structur
```

### 3. Compile a C Program

Using GCC:

```bash
gcc program_name.c -o program
```

### 4. Run the Program

**Windows:**

```bash
program.exe
```

**Linux / macOS:**

```bash
./program
```

## 💻 Example

For example, to compile a Stack program:
